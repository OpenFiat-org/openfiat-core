# openfiat-swqos

Stake-weighted quality of service: uses a wallet's reputation to influence
how a node prioritizes/rate-limits that peer's traffic. Architecture
scaffolding today — no logic implemented yet.

## Depends on

- `openfiat-network` — the transport whose traffic this would prioritize.
- `openfiat-reputation` — the scores this crate would weight by.
- `openfiat-types` — shared types.
