# Security Policy

## Supported Versions

OpenFiat is currently in active pre-release development (Version 1.0 draft).
Security fixes are applied to the `main` branch and the most recent tagged
release.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark:  |
| < 1.0   | :warning: best effort |

## Reporting a Vulnerability

**Do not open a public issue for security vulnerabilities.**

Please report suspected vulnerabilities privately using one of the following
channels:

1. [GitHub Security Advisories](../../security/advisories/new) for this
   repository (preferred).
2. Email **security@openfiat.org** with a description of the issue, steps to
   reproduce, and its potential impact.

You should receive an acknowledgement within **72 hours**. We will work with
you to understand and validate the issue, agree on a disclosure timeline, and
credit you in the release notes (unless you prefer to remain anonymous).

## Scope

This policy covers vulnerabilities in the code contained in this repository.
For vulnerabilities in the OpenFiat protocol specification itself, please
report to the [openfiat-specs](https://github.com/OpenFiat-org/openfiat-specs)
repository using the same process.

## Disclosure Policy

We follow coordinated disclosure. Once a fix is available, we will publish a
security advisory and, where applicable, a CVE. We ask that reporters give us
a reasonable window to ship a fix before public disclosure.
